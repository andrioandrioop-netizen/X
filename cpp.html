Q13.Write a program to reverse an array without using a second array.

{

Explanation

The program reverses an array without creating a second array. It swaps the first element with the last, the second with the second-last, and so on. Only the first half of the array needs to be processed because each swap handles two positions.

Q15.Write a program to find the transpose of the matrix.

transpose.cpp

#include<stdio.h>
#include<conio.h>

{

int r,c,i,j;

printf("Enter the number of rows:");
scanf("%d",&r);
printf("Enter the number of columns:");
scanf("%d",&c);

for(i=0;i<r;i++)
{
for(j=0;j<c;j++)
{
scanf("%d",&a[i][j]);
}
}
for (i=0;i<r;i++)
{
for(j=0;j<c;j++)
{
transpose[j][i]=a[i][j];
}
}
printf("\nTranspose of the matrix:\n");
for(i=0;i<c;i++)
{
for(j=0;j<r;j++)
{
printf("%d\t",transpose[i][j]);
}

}
getch();
}

Explanation

The program reads the rows and columns of a matrix and stores its elements in a two-dimensional array. To find the transpose, each element at a[i][j] is placed at transpose[j][i]. The transposed matrix is then printed with its rows and columns exchanged.

Q19.Write a program to reverse of a string.

reverse.cpp

#include <stdio.h>
#include <stdio.h>
#include <conio.h>
#include <string.h>
void reverseWord(char *start, char *end)
{
char temp;
while(start < end)
{
temp = *start;
*start = *end;
*end = temp;
start++;
end--;
}
}
void main()
{
char str[200];
char *word_start = NULL;
int i;
clrscr();
printf("Enter a string:\n");
gets(str);
for(i = 0; i <= strlen(str); i++)
{
if((word_start == NULL) && (str[i] != ' ' && str[i] != '\0'))
{
word_start = &str[i];
}
if(word_start && (str[i] == ' ' || str[i] == '\0'))
{
reverseWord(word_start, &str[i - 1]);
word_start = NULL; }
}
printf("\nString with each word reversed:\n%s", str);
getch();
}

Explanation

The program reverses each individual word in the entered string without changing the order of the words. It identifies the beginning and end of each word and passes those positions to reverseWord(), which swaps characters from both ends until the word is reversed.

Q21.Write program to find the factorial of a number using recursion.

factrecurr.cpp

#include <stdio.h>
#include <conio.h>
long factorial(int n)
{
if(n == 0 || n == 1)
return 1;
else
return n * factorial(n - 1);
}
void main()
{
int num;
long fact;
clrscr();
printf("Enter a number: ");
scanf("%d", &num);
fact = factorial(num);
printf("Factorial of %d = %ld", num, fact);
getch();
}

Explanation

The program calculates a factorial using recursion. The function returns 1 for 0 or 1, which is the base case. For any larger number, it returns n * factorial(n-1), causing the function to call itself until it reaches the base case.
